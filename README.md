# CircleBatumi

CircleBatumi არის GitHub Pages-ზე გასაშვები სტატიკური პროტოტიპი ბათუმში ნარჩენების ჩაბარების აღრიცხვისთვის.

## ფუნქციები
- ქართული ინტერფეისი
- ბათუმში ნარჩენების გადამამუშავებელი/მიმღები კომპანიების კატალოგი
- მოქალაქის და კომპანიის ანგარიშები
- username + password ავტორიზაცია 
- მოქალაქის მიერ ჩაბარების მოთხოვნის შექმნა
- კომპანიის მიერ ჩაბარების დადასტურება/უარყოფა
- კომპანიის მიერ მოქალაქისთვის პირდაპირი დადასტურებული ჩანაწერის შექმნა
- პირად პროფილში დადასტურებული კილოგრამების, კომპანიების, მასალებისა და ისტორიის ჩვენება
- უნიკალური CircleBatumi ჩანაწერის კოდი

## მნიშვნელოვანი ტექნიკური შენიშვნა
ეს არის front-end დემო. მომხმარებლები, პაროლის SHA-256 ჰეშები და ჩანაწერები ინახება ბრაუზერის `localStorage`-ში. ეს გამოდგება პრეზენტაციისა და პროტოტიპისთვის, მაგრამ არა რეალური მრავალმოწყობილობიანი სისტემისთვის.

რეალური ვერსიისთვის საჭიროა backend/database (მაგ. Supabase/Firebase/PostgreSQL) და უსაფრთხო server-side authentication.
